# Green Harvest

Green Harvest is a responsive landing page for an organic vegetable delivery
service. The project was developed by a team as part of a web development course.

## Links

- [Live demo](https://iv-hl.github.io/Cool_Developers/)
- [Source code](https://github.com/Iv-Hl/Cool_Developers)

## Features

- Responsive page layout for different screen sizes
- Sections presenting the service and its products
- Visual animations and transitions

## Tech stack

HTML5, CSS3, JavaScript, Vite, AOS, Animate.css, Git and GitHub.

## My role

**Team Lead**

I coordinated team collaboration and worked on page sections and animations.
The team used a shared GitHub repository and pull requests to integrate changes.

## Getting started

1. Clone the repository:

   `git clone https://github.com/Iv-Hl/Cool_Developers.git`

2. Open the project folder:

   `cd Cool_Developers`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local address shown in the terminal.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — build the project for GitHub Pages
- `npm run preview` — preview the production build locally

Team educational project.
